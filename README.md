# Factory0
Development of Factory0 Minecraft Modpack
Factory0 is a Satisfactory/Factorio inspired pack, but in no way am I trying to re-create the games.
The game will take place on a custom world with limited resources. The objective is for players to manage and optimize these resource nodes to create a factory.

### This pack is still very early in development. Features and Mechanics are subject to change.

## Platform
- Java NeoForge 1.21.1
- Planned Distribution: CurseForge
  
## What is being Developed
- Custom gameplay mechanics and recipes
- Quest book to guide progression
- Research tree with progression locks
- Custom 5,120 x 5,120 map.
    - Multiple starting locations, same map, different dimensions for multiplayer servers.
    - Currently trying to commission map.
    - https://docs.google.com/document/d/1J0J8EvVx3volhv7dNGEge8sUJeEZbSe6yTugbVWvrbo/edit?usp=sharing
